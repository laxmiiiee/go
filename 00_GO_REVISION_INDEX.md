## Important mental model

Go is:
- statically typed
- compiled
- garbage collected
- concurrent by design
- strongly typed
- designed around simple language primitives and powerful tooling

For interviews, focus on:
- WHY a feature exists
- WHAT happens at runtime
- trade-offs
- common traps
- production implications
- being able to explain the same concept using a real backend example

## Revision rule

For every topic, be able to answer:
1. What is it?
2. Why does Go have it?
3. How does it work?
4. What problem does it solve?
5. What is the common mistake?
6. When would I use it?
7. What is the alternative and trade-off?
